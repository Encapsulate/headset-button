# Raw captures from the reference device

These are unedited command outputs taken from the machine this project was
developed on, with the reference headset connected. They exist so you can diff
your own setup against a known-good one rather than trusting a summary.

| File | Command |
| --- | --- |
| `bluetoothctl-info.txt` | `bluetoothctl info 4C:FE:2E:8F:8D:8A` |
| `audio-topology.txt` | `pactl list cards` (bluez card), `pactl list short sinks/sources` |
| `environment.txt` | `uname`, `bluetoothd --version`, `hciconfig`, `gnome-shell --version`, `/etc/os-release` |

Notes:

* MAC addresses are the real ones and are not sensitive.
* `environment.txt` was captured over SSH, so session-type variables read
  `tty`/`unknown`; the desktop is GNOME on Wayland.
* Nothing here is generated by the test suite — it is evidence, not fixtures.

Narrative interpretation of all of this, plus what was *not* tested, is in
[../REFERENCE-HEADSET.md](../REFERENCE-HEADSET.md).
